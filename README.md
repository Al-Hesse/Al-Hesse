# About Me

Desenvolvedor de Software com sólida vivência no ciclo completo de desenvolvimento de aplicações modernas, com ênfase em engenharia de backend, arquitetura orientada a serviços (APIs RESTful), modelagem relacional de dados e infraestrutura containerizada com Docker.

Atuação técnica voltada para a entrega de soluções eficientes, escaláveis e com cobertura rigorosa de testes automatizados. Experiência na implementação de regras de negócio corporativas, fluxos seguros de autenticação e autorização (Spring Security, JWT), integração com serviços de pagamento e desenvolvimento de interfaces web responsivas com React e Tailwind CSS.

Graduando em **Análise e Desenvolvimento de Sistemas** pela **Faculdade de Tecnologia de Praia Grande (FATEC PG)**.

# Architecture & Engineering Principles

* **Clean Code & Legibilidade:** Código autoexplicativo, nomenclatura padronizada em conformidade com as PSRs (PHP), PEP 8 (Python) e convenções oficiais Java.
* **Testes Automatizados:** Testes como documentação viva do sistema, priorizando suítes rápidas e isolamento de dependências.
* **Segurança por Padrão:** Sanitização de entradas, proteção contra SQL Injection via ORM/Prepared Statements, hashing seguro de credenciais e proteção CSRF/CORS.
* **Versionamento Estruturado:** Commits atômicos, mensagens baseadas em Conventional Commits e rastreabilidade de alterações via Git.

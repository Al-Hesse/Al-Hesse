### Projetos em Destaque

#### 1. ZelaTech — Plataforma Web para Gestão e Manutenção Condominial
* **Visão Geral:** Sistema desenvolvido para digitalizar e otimizar processos de manutenção, registro de chamados operacionais e comunicação em condomínios residenciais e comerciais.
* **Arquitetura & Implementação:**
  * Backend estruturado em **Java 17** com **Spring Boot 3**, seguindo padrões de arquitetura em camadas e desacoplamento de responsabilidades.
  * Camada de segurança implementada com **Spring Security** e controle de acesso via tokens **JWT**.
  * Persistência de dados gerenciada com **Spring Data JPA / Hibernate** e banco relacional **MySQL 8.0**.
  * Integração com gateway de pagamentos **Asaas** para automatização de rotinas financeiras e cobranças condominiais.
  * Interface web desenvolvida em **React 18** com **Vite** e estilização utilitária via **Tailwind CSS**.
* **Repositório:** [github.com/Al-Hesse/ZelaTech](https://github.com/Al-Hesse/ZelaTech)

#### 2. SGA — Sistema de Gestão Acadêmica Institucional
* **Visão Geral:** Plataforma centralizada para instituições de ensino superior, unificando rotinas da secretaria administrativa e fluxos pedagógicos de coordenação e alunos.
* **Arquitetura & Implementação:**
  * Desenvolvido em **Python** utilizando o framework **Django**, implementando controle granular de permissões e regras de negócio acadêmicas.
  * Banco de dados **PostgreSQL 16** com integridade referencial estrita e migrações versionadas.
  * Ambiente integralmente containerizado através de **Docker** e orquestrado via **Docker Compose** com healthchecks de banco de dados.
  * Conjunto rigoroso de testes automatizados com **Pytest** e monitoramento de cobertura de código.
* **Repositório:** [github.com/joao-luizzz/SGA](https://github.com/joao-luizzz/SGA)

#### 3. API Cadastro de Filmes — Microsserviço RESTful em Laravel
* **Visão Geral:** API RESTful robusta desenvolvida para a disciplina de Programação para Dispositivos Móveis (PDM), projetada para consumo por aplicativos móveis em React Native / Expo.
* **Arquitetura & Implementação:**
  * Desenvolvida em **PHP 8** com **Laravel**, utilizando API Resources para serialização controlada de entidades JSON.
  * Implementação de pipeline multipart para upload e gerenciamento de arquivos físicos de mídia com resolução de URLs públicas absolutas.
  * Containerização completa através de imagem base Composer e orquestração por **Docker Compose**.
  * Cobertura de testes unitários e de integração (Feature Tests) com **PHPUnit** sob metodologia TDD.
* **Repositório:** [github.com/Al-Hesse/projeto_filme](https://github.com/Al-Hesse/projeto_filme)

#### 4. Inteligência Artificial & Ciência de Dados
* **Sofia — Assistente Virtual Financeira:** Solução interativa em Python voltada para consultoria e controle orçamentário pessoal, integrando modelos de linguagem e automações.
* **Detector de Fraudes:** Projeto analítico desenvolvido com Jupyter Notebooks, aplicando técnicas de manipulação e exploração de dados para identificação de padrões suspeitos em transações financeiras.

### Diretrizes de Engenharia e Boas Práticas

* **Clean Code & Legibilidade:** Código autoexplicativo, nomenclatura padronizada em conformidade com as PSRs (PHP), PEP 8 (Python) e convenções oficiais Java.
* **Testes Automatizados:** Testes como documentação viva do sistema, priorizando suítes rápidas e isolamento de dependências.
* **Segurança por Padrão:** Sanitização de entradas, proteção contra SQL Injection via ORM/Prepared Statements, hashing seguro de credenciais e proteção CSRF/CORS.
* **Versionamento Estruturado:** Commits atômicos, mensagens baseadas em Conventional Commits e rastreabilidade de alterações via Git.
